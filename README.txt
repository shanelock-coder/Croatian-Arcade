KRIŽALICA ARCADE V4 — CROATIAN LEARNING GAME
=============================================

V4 adds immersive WebXR support and a procedural soundtrack to the V3 course.

FILES
-----
index.html       Main game page
audio.js         Web Audio soundtrack + sound effects
vr.js            WebGL/WebXR VR Word Arena
app.js           Course/game UI and progression
course.js        Curated grammar chunks and examples
crossword.js     Crossword generator + validator
vocabulary.js    Croatian vocabulary database
style.css        UI, game, music and VR styling
VR_SETUP.txt     Quest/WebXR setup instructions

NORMAL DESKTOP USE
------------------
Double-click index.html. The existing course works without installation.

NEW: VR WORD ARENA
------------------
Each grammar unit can now be played as a spatial answer-selection game.
The desktop screen shows the same 3D room as a clickable preview.
On a compatible WebXR headset, press Enter VR and use controller rays + trigger.
The session also requests optional WebXR hand tracking.

IMPORTANT: immersive WebXR requires a secure context. For a Quest headset, host
this folder on an HTTPS static site and open that URL in Meta Quest Browser.
See VR_SETUP.txt.

NEW: SOUNDTRACK
---------------
The top-bar music button opens four modes:
- Auto: ambient for learning screens, DnB for active games
- Ambient: original generative study pad
- DnB: original procedural 174 BPM game loop
- Off

Audio is synthesized in the browser with Web Audio and does not use copyrighted
music files. Browsers require a click/tap before audio can begin.

COURSE + EXISTING GAMES

CROATIAN ACCURACY
------------------
Grammar transformations used by the learning chunks remain curated examples rather
than generated by a generic declension rule. Croatian characters Č Ć Đ Š Ž remain
supported throughout the app and on the crossword keyboard.
